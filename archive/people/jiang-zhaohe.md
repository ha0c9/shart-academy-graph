# 蒋兆和（1904—1986）

- 籍贯：四川泸州
- 与上海美专的关系：1930—1932 年任上海美术专科学校素描教授。
- 艺术领域：国画、美术教育
- 核实状态：已核实

## 生平简介

蒋兆和自学成才，融合西画素描与中国笔墨，开创现代水墨人物画。1943 年创作的长卷《流民图》真实描绘战乱中的难民，被汪伪当局禁展。1950 年起任中央美术学院教授，与徐悲鸿共同奠定“徐蒋体系”人物画教学。

## 主要贡献

- 开创现代水墨人物画
- 创作抗战时期巨作《流民图》
- 中央美术学院人物画教学体系奠基人之一

## 代表作品 / 著述

- 《流民图》
- 《杜甫像》
- 《卖子图》

蒋兆和（1904年5月9日—1986年4月15日），原名蒋万绥，男，籍贯湖北麻城，生于四川泸州，中国画家。


== 生平 ==
1920年于上海工作，曾写广告画，服装设计，自学西洋画。
1927年受聘于国立中央大学（1949年更名为南京大学），为图案系教员。1928年由徐悲鸿介绍，任职南京中央大学图案系教员。1930年至1932年，任上海美术专科学校素描教授。
一·二八事变，参予临时青年爱国宣传队，绘画抗日宣传画。1935年于北平画室授徒，为齐白石塑像。1936年返四川，开始现代水墨画人物创作。
1937年春返北平，七七事变后困于沦陷区，作画像及任京华美术学院和北平艺术专科学校教职。1947年任国立北平艺专教授。1950年起任中央美术学院教授。


== 家庭 ==
夫人萧琼，岳父萧龙友。


== 社会兼职 ==
中国美术家协会第二、三届理事，第四届顾问
中国文联委员
中国画研究院院务委员
第三、四、五、六届全国政协委员
民盟中央文教委员会委员


== 作品 ==
早期作品：《卖小吃的老人》、《卖子图》、巨幅画卷《流民图》等
后期作品:《小孩子与鸽子》、《杜甫像》等
1989年，《流民图》浮雕于泸县玉蟾山落成面世


== 奖项 ==
绘画《杜甫》获第六届全国美展荣誉奖。


== 展览 ==
1937年，在北平举办个人近作画展。
1943年，在北平举办《流民图》画展，被汪伪政府封禁，
1944年，转往上海外国租界展出。
1981年，先后在深圳、北京与夫人萧琼举行书画展。


== 出版 ==
《蒋兆和画册》、《蒋兆和画集》、《蒋兆和画选》等。


== 艺术教育论文 ==
《国画人物写生的教学问题》
《关于中国画的素描教学》
《中国水墨人物画的造型规律》


== 轶事 ==
蒋兆和诸多的古代名人像均是依照近现代名人画出的。如参照萧龙友画出的李时珍。
蒋兆和在中国大陆知名的画像《杜甫》实则是依照自己为原型画出的，在《杜甫》一画登入中国大陆高中教科书后，众多学生对此画进行再创作与恶搞，也使早已离世的蒋兆和先生又红了一次。
