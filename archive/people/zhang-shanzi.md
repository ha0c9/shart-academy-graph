# 张善孖（1882—1940）

- 别名 / 备注：名泽，号虎痴
- 籍贯：四川内江
- 与上海美专的关系：曾任教于上海美专。
- 艺术领域：国画
- 核实状态：部分核实

## 生平简介

张善孖是张大千的二哥，以画虎闻名，曾在家中饲养老虎写生，号“虎痴”。抗战期间赴欧美举办画展募款支援抗战，1940 年在重庆病逝。

## 主要贡献

- 以画虎著称的近代国画家
- 抗战期间海外办展募捐

张善孖（1882年7月12日—1940年10月20日），原名张正兰，后改名张泽，字善孖，号虎痴，教名安琪，四川内江人，中国画家，以画虎闻名。


== 生平 ==

曾任教于上海美专。依其母亲遗愿，张善孖于1938年12月8日在云南昆明受洗皈依罗马天主教，仪式由南京教区主教于斌主持。1940年因心脏病逝世于重庆，于斌为他举行了临终圣事。同年10月30日在美国纽约市圣安德肋堂为他举行了安魂弥撒。


== 家族 ==
父张怀忠。母曾友贞，天主教徒，画家。家中有兄弟十人，张善孖排行第二，弟张大千排行第八。


== 逸事 ==
张善孖善画虎，曾拜李瑞清门下，为了画虎，曾在家中饲养老虎，因此号虎痴。
他善武术气功，为自然门门下。
