# 王攀元（1909—2017）

- 籍贯：江苏
- 与上海美专的关系：1933 年考入上海美专西画科，师从张弦、潘玉良、王济远、潘天寿等，1936 年毕业。
- 艺术领域：油画、国画
- 核实状态：已核实

## 生平简介

王攀元 1949 年赴台，1952 年起在宜兰罗东中学任美术教师并定居当地。作品构图简约，常以孤帆、伫影、奔犬、瘦马寄托乡愁与孤独，2001 年获台湾第五届国家文艺奖，享寿逾百岁。

## 主要贡献

- 台湾现代水彩、油画代表画家
- 长期在宜兰从事美术教育

## 代表作品 / 著述

- 《思故乡》
- 《奔驰的狗》

王攀元（1908年或1909年－2017年12月22日），台湾画家，生于江苏。幼时求学过程缺乏经济支援因此相当艰苦，最终毕业于上海美专西画科。国共内战后迁徙至台湾，辗转定居宜兰担任罗东中学美术老师，同时创作，并于2001年获得第五届国家文艺奖。王攀元画作构图简约，具象征性并且能表达独特而深刻的情绪。


== 生平 ==
王攀元，1908年（或1909年）生为江苏望族二少爷，三岁、十三岁时父母分别逝世。小学毕业后考上江苏省立淮安中学，家族却对他求学之事不太热衷，休学一年后，经同情他的亲友与佃农资助，终于再度正式入学。1933年考上复旦大学法律系，因志趣不合又重考进上海美专西画科，师从张弦，同时期美专中的老师还有陈人浩、潘玉良、王济远和潘天寿。由于王攀元依旧没有经济后盾，需透过打工赚取生活费，学杂费则借助吴茀之提供之优待。1936年毕业，原与红粉知己季竹君相约，欲随潘玉良老师赴法留学，但适逢中法战争而未成行。1949年为远离国共内战，携妻子倪月清及长女搭船至台湾，先落脚高雄凤山，在码头当搬运杂工。1952年经堂弟推介至宜兰罗东中学任美术老师并就此定居，任教期间即便生活困苦仍坚持作画。至1973年6月退休后将更多时间投入创作中。王攀元于1969年入选全省特殊优良教师，2001年获得第五届国家文艺奖，于2017年12月22日辞世，享寿过百。


== 创作特色与风格 ==
王攀元虽然是学西画出身，但因负担不起油画颜料的费用因此水彩作品数量较多。作品画面多以平涂或厚涂方式绘制大面积色块，亦常见动物及人物的元素，整体图像简洁俐落，带有印象主义的影响并且能表达独特而深刻的情绪。王攀元自幼爱读诗词，并保有每天写日记的习惯，其作品多能和日记记录之心境呼应，透过日记可发现由于失怙、离乡且生活坎坷，使其将作画当成倾吐与诉说心愿的管道。黄光男指出王攀元作品画面上充满伫影、孤帆、奔犬、瘦马，如此梦境般的场景与象征符号，是一种经过情感压抑的潜影。进一步分析可得出“凝缩作用”（如1964年《倦客》、1972年《思故乡》）与“置换作用”（如1982年《皆不是》、1985年《奔驰的狗》）两种特色。伫影、孤帆、奔犬与瘦马代表王攀元自己与孤独，而太阳、海鸟、房舍则代表故乡、爱人、温暖。


== 展出经历 ==
1959年，在宜兰罗东农会开第一次画展，卖出所有展出的三十幅水墨及水彩。
1966年(民国五十五年)，在台北的画友李德协助下，在亚洲国际画廊举办首次个人画展。
1979年(民国六十八年)，在老友李德的劝说下，再次在台北春之艺廊展出画作。
1983年，获得中华民国画学会金爵奖，受邀在台北市立美术馆名人画廊举办水彩画展。
1985年，参加韩国第一届亚洲国际美展，之后持续参加十六届。
1986年(民国七十五年)，首次水墨画展于雄狮画廊。
1987年(民国七十六年)，在台北皇冠艺文中心举办个展，应邀在国立历史博物馆国家画廊举行个展。
1988年，应邀参加全国美展、亚洲国际美展、国家画廊当代艺术展联展。
1989年，参加全国美展，以及国立历史博物馆国家画廊主办之“当代艺术发展展”。
1990年，台北“亚洲艺术中心”个展。
1991年，台湾省立美术馆二度典藏作品。
1992年，台北“诚品画廊”个展、台中省立美术馆个展。
1992年3月(民国八十一年三月)，苏富比公司首次在台北市举行绘画拍卖会，油画“风景”以一百万元、水彩“拜石图”六十万元成交，次日报上誉为“八大明星画家之一”。
1994年，台北“形而上画廊”举办“孤独原来不寂寞”个展。
1995年，在台北“形而上画廊”举办“不只是孤独”个展。高雄市立美术馆典藏油画与水彩作品。
1997年，台北国际艺术博览会特展。
2001年5月-6月于国立历史博物馆举行王攀元老师九十自选展。
2018年5月4日国立历史博物馆主办“过尽千帆——王攀元绘画艺术”展出王攀元老师近150画作。作品来源包括国立历史博物馆馆藏、台北市立美术馆馆藏，私人收藏家及其家属收藏；画作媒材分为油彩、水彩与水墨三大类；依主题则分为山、水、船、孤独人影、人群、包括黄山、北大荒与东北雪景、中国山水回忆与兰阳雨、太平山、苏澳港与龟山岛等台湾景物之美；首度亮相的70幅水墨画作包括中国传统宋朝、元朝山水画与若八大山人笔下的孤独鸟；开幕展上有国立历史博物馆馆长廖新田、中华民国文化部郑丽君、资深艺术家谢里法、资深艺术家廖修平与编舞家姚淑芬。
2019年10月19日亚洲艺术中心主办“风林火山——源自东方的抽象”群展，与陈庭诗、杨英风、刘生容、李元佳、朱为白、李芳枝、冯锺睿、庄喆、李锡奇、韩湘宁共同在北京798艺术区展出。
