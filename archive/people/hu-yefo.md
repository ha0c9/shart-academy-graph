# 胡也佛（1908—1980）

- 别名 / 备注：原名胡国华，字大空
- 籍贯：浙江余姚坎墩（今属慈溪）
- 与上海美专的关系：只身来上海就读于上海美专，后转入新华艺专。
- 艺术领域：国画、漫画连环画
- 核实状态：部分核实

## 生平简介

胡也佛是连环画、仕女画、工笔画家。1929 年入上海商务印书馆美术编辑部，以“胡若佛”笔名画儿童读物；1958 年任朵云轩水印木刻社勾描组长，接触大量古画真迹。业余与张令涛合作，为多家人民美术出版社绘制《红楼梦》《西厢记》《三国演义》等古装连环画二十余种。

胡也佛（1908年—1980年），原名胡国华，字大空，号谷华，署名十卉庐主，笔名胡若佛、胡也佛、胡丁文、胡新、胡强，浙江余姚人，连环画、春宫画、仕女画、工笔画家。


== 生平 ==
清朝光绪三十四年（1908年），生于浙江余姚坎敦（现慈溪），本名国华，十岁时出嗣给作义学校长的叔祖母。叔祖母见其自幼爱画图，于十四岁送至宁波上中学，之后只身来上海就读于上海美专，后转入新华艺专，打下西洋画的基础。因经济上欠佳，以变卖家产维持，有时替白俄罗斯老师代笔在法国总会画壁画挣几块大洋贴补，最后一学期因经济辍学，校方依然赠给毕业文凭。1927年考入南京国民政府总政治部当上尉宣传员，次年任少校副官，随蔡公时去济南而爆发五三惨案，胡也佛中流弹跳窗脱险。
1929年辞去公职，进入上海商务印书馆美术编辑部任高级职员，笔名胡若佛，画儿童读物外销南洋，薪金颇丰。一家六口，妻子小胡也佛两岁，生于富裕之家，体弱多病。1934年，妻子及两女儿染上肺痨，女儿们相继夭折。抗战前夕，胡也佛被辞退，经营过照相馆、糖果食品店、儿童读物书店、连环画出版社，因不擅经营，均不到一年而倒闭。后又在出版地图的世界舆地学社任职一年，始学中国画，笔名胡也佛。他曾对刚满十二岁小学的儿子说不要当画家而要当医生。因而“佛”与“空”有联系，加上钱柜已空、“色即是空”，便用“大空堂”为画室名。为妻子医药费及儿女的学杂费，于1945年前后开始画春宫画，之后家中经济明显好转，定价的标准按一両黄金画三张，需时约两个月。1949年前后，连环画出版事业始有起色，胡也佛受聘于灯塔出版社，1952年公私合营转入新美术图画书店，后复经上海人民美术出版社，于1958年去“朵云轩”水印木刻社任勾描组长。因工作需要，接触大量古画真迹。工作下班后业余时间，与年青时商务印书馆时的同事张令涛合作，以胡若佛、胡丁文、胡新、胡强为笔名，先后为北京、朝花、天津、河北、上海等人民美术出版社，绘制古装连环累计廿余种，收入甚好。战后肺痨已非绝症，妻子终于痊愈。
1949年土改时，胡也佛在履历表自填地主（文革后才纠正为自由职业者）。在1952年上海公安局北站分局通知：“按解放前民事案件免予处理，但画稿原件需全部收回上缴销毁，具结今后不得再画。”此后他没有再春宫画，连工笔仕女也极少画，最多不超过十幅。在文革期间因地主、春宫画的罪名，被批斗百余次。
患肺癌，于上海逝世，享年七十二岁。


== 作品 ==
胡也佛的春宫画《金瓶梅秘戏图》，共创作30幅。既重写意、也重写实，运用西洋画中透视，精细勾勒，体现出几分幽人野客之致。
