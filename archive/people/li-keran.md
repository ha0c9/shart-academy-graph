# 李可染（1907—1989）

- 别名 / 备注：原名李永顺，斋号师牛堂
- 籍贯：江苏徐州
- 与上海美专的关系：1923 年考入上海美专师范科（1925 年毕业），后入杭州国立艺专研究部。
- 艺术领域：国画、美术教育
- 核实状态：已核实

## 生平简介

李可染是中国山水画现代转型的核心奠基人，以山水和牛著称。他 16 岁考入上海美专师范科，后入杭州国立艺专，受林风眠、潘天寿影响。抗战期间在郭沫若领导的政治部三厅从事抗日宣传。

1946 年应徐悲鸿之邀任教北平国立艺专，先后师从齐白石、黄宾虹。1954 年起多次长途写生，创造“积墨”与“积色”结合的“李家山水”，代表作《万山红遍》。1981 年任中国画研究院院长，1979 年、1985 年当选中国美协副主席。

李可染（1907年3月26日—1989年12月5日），原名李永顺，斋号师牛堂，江苏徐州人，中国当代画家，中国山水画现代转型的核心奠基人。以创作山水画、动物画为主，尤其喜爱画牛。


== 生平 ==
李可染出生于徐州的一个农民家庭。李可染从小喜欢绘画，13岁便从师当地画家钱食芝学习八大山人的山水画画法。1923年考入上海美专师范科，1929年考入蔡元培开办的杭州国立艺术专科学院。此时他接触了油画，又受林风眠、潘天寿影响，探讨传统水墨画的革新问题。1932年举行第一次个人画展。其创作的《锺馗》于1937年入选南京第二届全国美展。
1938年抗日战争期间，他到武汉参加郭沫若领导的政治部三厅从事抗日宣传工作。期间较受注意的宣传作品如《是谁破坏了你快乐的家园！》等，多存在报纸等大量复制品，其余墙壁上所作仅有底片留存。
1939年武汉危急，李可染辗转经长沙、贵阳取道入重庆。1942年于重庆致力创作，参加当代画家联展，发表《屈原》《王羲之》《风雨归牧》《牧童遥指杏花村》等，其中《牧童遥指杏花村》为徐悲鸿订购。李可染在重庆居所靠近牛棚，此后有更多画牛的主题。1943年任重庆国立艺专讲师，1944年在重庆中苏友好协会举办国画个展。1946年应徐悲鸿之邀赴北平国立艺专任教，并与林风眠、方干民、吴大羽、朱德群、赵无极、胡善余等参加重庆“独立美展”。1949年创作写意人物画《街头卖唱图》。
1954年与张仃、罗铭一同旅行写生。1957年与关良访问东德并在柏林科学院举办画展，两年后又在布拉格举办画展并出版画集。1964年创作了《万山红遍》，将传统的“积墨法”和自己自创的“积色法”相结合。1974年在批“黑画”运动中受到批斗，文化大革命期间停画6年。1979年当选为中国美协副主席，1981年任中国画研究院院长，1985年再次当选为中国美协副主席。1989年逝世于北京西城区，遗体葬于八宝山革命公墓。

儿子李小可为画家、摄影师、中央文史研究馆馆员。

== 创作概要 ==
李可染以山水画闻名于艺术界，中国写意人物画亦有相当研究，其风格影响了颇多后来者，诸如刘大为、陈玉先、冯远等人。其山水画代表作有《漓江胜境》与《万山红遍》等。李喜欢画牛，也是书法家。

== 作品拍卖纪录 ==
2007年5月3日《万山红遍》在香港佳士得“中国近现代书画”及“中国古代书画”春季拍卖以逾三千五百万港元高价成交，打破画家作品最高成交价的世界纪录。
2012年1月7日中国现代著名画家李可染的红色经典名作《革命圣地韶山》在南京经典拍卖有限公司的2011秋季艺术品拍卖会上，以6842.5万元的高价成交
2012年5月12日中国现代著名画家李可染的红色经典名作《韶山》在中国嘉德2012春拍以1.242亿元人民币的天价成交，刷新了其作品拍卖纪录
2012年6月3日中国现代著名画家李可染的红色经典名作《万山红遍》在北京保利国际拍卖有限公司2012春季拍卖会“中国近现代书画夜场”上，以2.9亿元（人民币．下同）成交，刷新今年春拍成交纪录，成为迄今个人画作拍卖史上最高价的艺术品。
