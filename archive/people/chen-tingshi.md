# 陈庭诗（1913—2002）

- 别名 / 备注：笔名耳氏
- 籍贯：福建长乐
- 与上海美专的关系：1937 年进入上海美专就读，同年抗战爆发。
- 艺术领域：版画、雕塑
- 核实状态：已核实

## 生平简介

陈庭诗幼年因意外失聪，抗战时期以“耳氏”为笔名创作抗敌漫画与木刻。1945 年赴台，1958 年参与创立“中国现代版画会”，以甘蔗板版画闻名，1970 年获首届韩国国际版画双年展首奖。后期创作现成物铁雕，《约翰走路》被收入《二十世纪的艺术》。

## 主要贡献

- 台湾现代版画先驱
- 现成物铁雕艺术家

陈庭诗（1913年11月28日—2002年4月15日），笔名耳氏，男，福建长乐人，故宫研究员楚戈称他是艺术上的“国宝” ，前高雄美术馆馆长李俊贤和艺术评论家陆蓉之不约而同认为他就像是一部“美术史”。家族属福州望族，八岁时因为嬉戏不慎从高处跌下，以致损坏听觉。
生涯早期在躲避战火同时也透过艺术救国，辗转来台后又因为二二八事件的波及而暂停艺术创作。1957年开始以当时产量丰富的甘蔗板进行版画创作，将甘蔗板的特性发挥至极致，版画作品《蛰》在1970年获得第一届“韩国国际版画双年展”首奖。创作后期将重心转至现成物雕塑，以《约翰走路》一作名列《二十世纪的艺术》一书〈铁与空间大师〉篇章之中，在全球的二十世纪艺术史上留名。
一生创作版图多元，以版画、雕塑闻名，另有许多彩墨、亚克力、诗及书法作品。逝世前授权友人成立“财团法人陈庭诗现代艺术基金会”，首任董事长为钟俊雄。另外，国立台湾美术馆、台北市立美术馆、高雄市立美术馆、台中市政府文化局、辛辛那提美术馆、洛克菲勒基金会等皆有典藏其作品。


== 写实木刻版画时期 ==
1937年，进入上海美专就读，同年爆发七七事变。隔年，八年抗战展开，陈庭诗以“耳氏”为笔名参与《抗敌漫画》，后与宋秉衡等人共同主编《大众画刊》(隶属于福建君管区国民军训处的机关刊物)。1942-1945间辗转任职赣州“正气中华出版社”编辑、“教育部巡回戏剧教育部队”绘画与舞台设计。
1945年底，陈庭诗来到台湾，筹备隔年《和平日报》台中分社的创刊，担任美术编辑。隔年4月10日，台中分社《和平日报》创刊，往后陈庭诗在其主编的〈新世纪副刊〉及〈每周画刊〉专栏中，经常刊登讽刺时政漫画，他还开辟〈污吏别传〉漫画专栏。在其主编的版面时常可以看到黄荣灿的作品或文章与他的漫画并置。同年与和平日报编辑王思祥相偕漫游全岛，在《和平日报》开辟“环岛行脚见闻”连载，也为杨逵所办的《文化交流》做美编并刊录个人漫画作品。
1947年二二八事件后，《和平日报》被政府查封，为了躲避查缉而返回中国任福州《闽星日报》编辑。1948年，应邀再度来台为台湾省立台北图书馆（今国立台湾图书馆）绘制巨幅《刘铭传督建铁路图》油画，后留任台湾省立台北图书馆任馆员。1948至1949年间，大部分的木刻家都在风声鹤唳下相继离台，只剩黄荣灿与陈庭诗。1951年的白色恐怖时期，木刻家黄荣灿自师大教员宿舍被拖出逮捕，1952年被冠以叛乱罪在马场町处决。任职于图书馆的1948至1957年间，是陈庭诗的沈潜时期，工作期间的大量阅读西洋画册，对于后期抽象提炼与传达提供了丰沃的土壤。


== 抽象表达时期 ==
1957年，辞去图书馆的工作之后，重新投入创作。当年五月与东方两画会皆举办第一届画展，隔年在“第一届中美现代版画展”成功的鼓舞之下，于1958年与秦松、李锡奇、杨英风、江汉东、施骅共同创立“中国现代版画会”。这时陈庭诗的版画已开始具有现代抽象风格的雏形，1959年获选以《阵雨》（骤雨）参加巴西第五届圣保罗国际双年展，一举跃身国际。在画会的成员的互相激励、较劲当中，陈庭诗也渐渐以天地、日月星辰、生生不息循环等概念开启自身独特的创作风格。
1969年，陈庭诗以《蛰》在两百多位艺术家的参展作品当中，获得1970年第一届“韩国国际版画双年展”首奖。这是由韩国《东亚日报》举办的首届国际版画展，由英、法、日、西德四国艺评家担任评审，委员一致认为陈庭诗的作品深具东方精神特色，沈凝洗练、潜藏力感，评为“穿破黑暗的光明”。
在1971至1999年间，陈庭诗以湛蓝的“星星的假期”系列、大红的《新生》、《灯会》、红黑对比的“昼与夜”系列、书法变奏的“梦在冰河”系列，达到一生版画创作的高峰。其中，1976-1978 陈庭诗旅居美国，期间除了参与科罗拉多州政府议会大厦设计-“纪念华工移民开拓”的镶嵌玻璃画之外，也勤跑艺文机构、举办个展，获评论家 James Mills 评论其作品‘重为轻根，静为燥君’。


== 现成物雕塑时期 ==
1960年代末期，陈庭诗受到毕加索现成物雕塑《公牛头》的启发，开启现成物雕塑的创造。初时使用破铜、废铁、流木等拼凑而成。迁居台中太平之后，不断搜集各种媒材进行现成物雕塑，时常会至高雄拆船工业区搜罗可以用来创作的废船五金，先请当地工匠纪秋永处理后，再运回台中或高雄朋友家就近拼组废铁。
1996年12月，在台北市立美术馆举办的“赛撒回顾展”当中，两人首次相见。1998年，陈庭诗获邀参加西班牙举行的“铸造一个空间”巡回展，以《约翰走路》、《凤凰》两件作品参展。在包括毕加索、贡萨列、奇利达、卡尔达、塞撒、丁格利等四十位各国重要金属雕塑家的参展作品中共同展出。
1999年，《二十世纪的艺术》一书于〈铁与空间大师〉的篇章之中，陈庭诗的名字及《约翰走路》与世界著名的雕塑家同列，陈庭诗是全书除了贝聿铭外，唯一的华人艺术家
2018年，台中市政府文化局修复完历史建筑-太平买烟场后于此成立“陈庭诗纪念美术馆”。
