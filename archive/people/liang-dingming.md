# 梁鼎铭（1898—1959）

- 别名 / 备注：本名梁协燊，自署战画室主
- 籍贯：上海（籍贯广东顺德）
- 与上海美专的关系：1915 年就读南洋测绘学校时，同时入上海图画美术院习画。
- 艺术领域：油画、国画
- 核实状态：已核实

## 生平简介

梁鼎铭以战争史画著称，北伐时期任《革命画报》主编。1930 年南京国民政府在灵谷寺附近为其建画室，创作国民革命军阵亡将士纪念史画。1947 年迁居台湾，后主持政工干校美术组。现存巨幅史画《血刃图》藏国立台湾美术馆。

梁鼎铭（1898年—1959年3月1日），本名梁协燊，为近代中国画家，自署战画室主。广东顺德人。清光绪二十三（公元1898年）年生于上海。是双胞胎画家梁又铭、梁中铭的二哥。大姐梁雪清。


== 生平 ==


==== 求学、上海就业 ====
梁鼎铭于1898年生于上海，1907年入私塾启蒙。1915年就读南洋测绘学校时，透过课程接触透视技巧，同时入“上海图画美术院”习画。 1916年在厦门以绘制人物肖像谋生。1917年10月以晨妆梳罢画作获得东雅公司月份牌征稿第二名， 进入上海英美烟草公司广告部绘画美人图。1919年秋，大哥粱砥中赴法“勤工俭学”研习艺术方面课程，购买画册、复制品邮寄回国，给家族作为学画临摹范本，他一边临摹，也指导双胞胎弟弟梁又铭、梁中铭习画。 


==== 参与军中艺术文宣 ====
1925年秋，他辞去工作，前往广东开展。1926年被任命为《革命画报》主编，同年在广州近郊大石头开设“穗石乡画室”完成沙基血迹图，开始创作大型战画。 1926年7月起，他陆续担任国民革命军总司令部政治部中校艺术股长、第八路军中校艺术股长、军事委员会总政治作战部中校艺术科长，12月改派为训练总监部政治训练处中校艺术股长等职。1929年3月透过南京国民政府训令出发前往法、比、德、义等国考察美术。 1930年4月，南京国民政府筹备国民革命军阵亡将士公墓筹备委员会及纪念馆，于灵谷寺附近起建画室，由他创作史画。1934年起，他兼任陆军军官学校政治训练处上校政治教官，经评估堪任职务部分有“堪任大学校美术学院院长”语。 1930年8月与李若兰成婚。二人婚后共育有2子：梁小鼎（1937年夭折）、梁灼华，5女：梁丹美、梁丹丰、梁丹平、梁丹贝、梁丹卉，均为台湾艺文界人物。


==== 战乱迁徙、定居台湾 ====
中日全面战争期间，梁鼎铭一家迁徙武汉、四川。1941年底，他前往香港，准备赴美进行文化宣传之际，因太平洋战争爆发香港沦陷，乃被迫毁坏10余幅大幅油画，仅留下血刃图存放友人处。1942年间顺利逃离香港，6月到广西柳州担任中学校长，1946年出任东北吉林中正艺专校长。 1947年冬，全家由上海移居台北。1951年6月，他任职日本盟军总部心理作战部，期间接触前卫绘画。1952年返回台湾。1955年起，接替刘狮出任政工干校（现国防大学政治作战学院）美术组主任，为健全政工干校美术科教学内容，他亲自劝说林克恭、蓝荫鼎到校授课。同时，他更将水墨人物画列为必修课程，增设实用美术课程，并编写教材、教授解剖课、制作相关绘图仪器。他也曾担任教育部美育委员审定美术教材 。


== 艺术创作 ==
梁鼎铭早年从事人物肖像、美人图等商业创作。前往欧洲考察美术后，从事油画战史题材创作，为创作生涯之高峰。另以素描、动物（马）题材见长，也尝试版画创作。彭明辉指出，他结合中国传统绘画和西洋绘画之长，使人物、风景、动物等题材之描绘生动活泼。 他曾经尝试在商业创作中运用色粉笔、水彩等混合媒材。另外，他早年创作的美人画，在描绘传统服饰人物及历史主题外，也加入肖像画、炭精媒材，以凸显人物主题光影对比及立体感，呈现中西合璧的特色。 彭明辉指出，他为了画马，曾经取得马匹骨骼仔细研究生理构造，以求形神兼具。他画出的马匹，以马蹄不着地具有腾空姿态而知名。 


==== 史画 ====
陈佩佩认为，梁鼎铭在题材、形式、风格上取法浪漫主义绘画风格，作为战争史画范本，表现视觉上的震撼。经由政党安排、资助，他的战争史画甚具宣传效果，激励士气。评论者认为这是他实践“美术救国”、“以美术见证时代”信念的展现。 
他创作巨幅史画十五幅，至今仅存1938年完成油画血刃图（国立台湾美术馆典藏）及1950年完成油画岳飞大破拐子马图（国立历史博物馆典藏）。1971年，梁丹丰重绘惠州战役图，将原画尺寸缩小1/3比例（212×798CM）依原画完成，保存于中国文化大学华冈博物馆，是台湾现存最大战画。
