# 陈田鹤（1911—1955）

- 别名 / 备注：原名陈启东
- 籍贯：浙江永嘉（今温州）
- 与上海美专的关系：1929 年入上海美专音乐组，师从刘梦非、宋昌寿。
- 艺术领域：音乐
- 核实状态：已核实

## 生平简介

陈田鹤后入国立音专，拜黄自为师。他创作了《还我河山》《巷战歌》等大量抗战歌曲，1936 年所作《哀挽一位民族解放的战士》是当时唯一悼念鲁迅的艺术歌曲。1940 年代任教国立重庆音乐学院作曲系。

## 主要贡献

- 抗战歌曲作曲家
- 中国艺术歌曲代表作曲家

## 代表作品 / 著述

- 《还我河山》
- 《山中》（徐志摩词）
- 歌剧《荆轲》

陈田鹤，Chen Tianhe（1911年12月8日—1955年10月23日），原名陈启东，浙江温州永嘉县人，中国作曲家。


== 生平 ==
父姓詹，从事账房。陈田鹤是家中长子，九岁丧母，自幼便寄养在陈姓外祖父家，随母姓，取名启东。
六岁时，听道士们奏法事音乐，竟一夜忘归。十一岁进永嘉县模范初级小学（今瓦市小学），毕业后入永嘉县立第一小学（今广场路小学）。1925年秋考入省立温州第十中学（今温州中学），一年半后肄业参加北伐军。温州中学读书时，在留日归来的金荣轩影响下学习日语，日后翻译日本音乐家的文章。
1928年进入温州艺术学院，师从缪天瑞学习理论作曲，兼选修钢琴。1929年入上海美专音乐组，师从刘梦非、宋昌寿。1930年9月，改名陈田鹤，入上海国立音乐学院作曲系选修，师从萧友梅院长学习理论作曲，并拜入黄自门下。在上海国立音专求学六年间，因环境生活所迫曾三次辍学。
1930年，翻译门马直卫《曲调的转调》、1934年翻译兼常清佐原作《音与言语与酒味》。1934年至1935年任教于武昌艺术专科学校。1936年鲁迅去世，作《哀挽一位民族解放的战士》，是当时悼念鲁迅的唯一一首艺术歌曲。1940年至1949年任教于国立重庆音乐学院作曲系。
九一八事变后，创作《认清敌人》、《我们要夺回失去的地》、《我们要振起精神》等歌曲。对日抗战期间，创作《巷战歌》、《八一三战歌》、《保卫上海》、《敬献给誓守闸北的八百壮士》等，这些歌曲当年流行于大后方。1939年5月3日，日本轰炸重庆，在防空洞里谱写钢琴曲《血债》。当年还以朱偰的词，谱出著名的抗战歌曲《还我河山》。
1945年抗战胜利，国立重庆音乐学院作曲系迁南京复校，仍任教授兼任教务主任。同年记录整理出丑辉瑛演唱的《在那遥远的地方》，谱成钢琴曲。
1949年为躲避战乱，改任教于国立福建音乐专科学校作曲组教授，而认识李永刚。同年8月被选为福州市第一届人民代表大会代表，并去华东革命大学学习半年。1951年任北京人民艺术剧院任作曲员。1954年任中央歌舞团作曲员。1955年任中央实验歌剧院作曲员。
1955年7月，因痢疾及心脏病突发入院，当年10月23日病逝北京通县。


== 身后 ==
1981年，廖辅叔在《人民音乐》发表〈追怀田鹤〉；1985年，常罡发表〈陈田鹤及其歌曲创作〉于《音乐研究》；1991年，人民音乐出版社出版《陈田鹤歌曲选集》，同年徐志摩作词的作品《山中》被香港中国艺术歌曲演唱比赛定为指定曲目；1993年，东方出版社出版刘梦非著《音乐之子——陈田鹤大师传》；1995年，陈田鹤逝世四十周年，纪念音乐会在中央音乐学院举行；2011年5月，陈田鹤诞辰百年纪念活动在中央音乐学院举办，并召开陈田鹤学术研讨会，《中央音乐学院学报》（季刊）第3期封面刊登陈田鹤照片，又刊载论文《1949年后的陈田鹤》。
刻画抗战时中国知识阶层形象的国画长卷《浩气长流》有其画像。


== 作品 ==
从二十岁发表第一部作品《谁伴明窗独坐》以来，其作品达200余部。曾涉足电影界，为艺华影业有限公司等摄制的故事片《银海浮云》、《女人》、《冷月诗魂》等，创作《定情曲》、《好宝宝》、《定情之歌》、《冷月诗魂》等插曲和主题歌。除歌曲作品，还创作歌剧《荆轲》、《桃花源》，清唱剧《河梁话别》等。作品除发表在各种音乐刊物上外﹐收集成书的有《回忆集》(1937年)﹑《剑声集》(1943年)等。


== 家庭 ==
育有陈敦秀、陈敦丽两女。
