# 常玉（1895—1966）

- 别名 / 备注：本名常幼书；被称为“东方马蒂斯”
- 籍贯：四川南充
- 与上海美专的关系：1917 年进入上海美术专科学校就读，1920 年赴法国留学。
- 艺术领域：油画
- 核实状态：已核实

## 生平简介

常玉是旅法华人画家，画风中西融合，以简约的线条、平涂色块描绘女性裸体、花卉与动物，常被称为“东方马蒂斯”。1920 年赴巴黎后长居法国，参与秋季沙龙、独立沙龙，1966 年在巴黎工作室煤气中毒去世。

他生前寄往台湾准备展览的 42 幅作品后由台北国立历史博物馆典藏，该馆共藏其作品 52 幅，其中《菊》与《四裸女》被列为重要古物。

## 主要贡献

- 20 世纪中西融合绘画的代表
- 作品成为台北国立历史博物馆重要典藏

常玉（1895年10月14日—1966年8月12日），著名法国华人画家，四川省顺庆（现南充市）人，在家排行老六，本名常幼书。画风中西融合，常被称为“东方马蒂斯”、“自由中国的莫迪利亚尼”。


== 生平 ==
1895年出生于四川顺庆府南充县的富商家庭，1910年即与赵熙习画，1917年（谎报年龄为1895年）才得以进入上海美术专科学校就读，少年时就读上海美术学校，1919年赴日时在东京展出其书法作品，而获当地杂志刊载推荐。在五四运动掀起的热潮下，由大哥常廷杰全额资助，于1920年转赴法国留学，与徐悲鸿，林风眠、颜文梁、方干民等成为中国最早期的留法学生之一，之后留居巴黎。在巴黎落脚后，常玉随即融入当时极富艺术气息的生活方式。在大茅舍艺术学院习画，或在蒙帕纳斯的咖啡馆流连。至1966年辞世，大致都住在巴黎，仅于1938年短期回国。
1921年与徐悲鸿、张道藩等留法学生组织“天狗会”。1925年作品入选法国秋季沙龙元。常玉于1929年与在大茅屋结识的法籍美术学生哈蒙尼耶小姐结婚，但婚姻只维持了短暂的两年。同年，常玉认识了当时巴黎最大的收藏家Pierre-Henri Hoché，他的作品开始被法国画坛注意及收藏，并于多间画廊展出，多次参与秋季沙龙及独立沙龙展。
1929年，与刘海粟、颜文梁等人创办中华留法艺术协会，集合了刘海粟、颜文梁、范年、常玉、杨秀涛、张弦、汪亚尘、汪日章、庞熏琹、司徒乔、陆鼎萱及陈国芳等旅法美术家。
1931年为法文版“陶潜诗集”作插图。1932年被列入《1910年至1930年当代艺术家生平辞典》第三卷。1933年在阿姆斯特丹举办画展。二次大战前，1938年因兄丧返国，同年（次年？）返回法国巴黎。1948年由法国赴美，纽约现代美术馆替他举办个展，居留美国纽约生活两年。

二次世界大战结束后，常玉选择留在巴黎。深具艺术家个性的他不谙经营自己、和巴黎画商渐行渐远，还肆意挥霍家产。从车马轻裘、醇酒美人的浪荡子，转为穷困潦倒的失意画家。1955年作品参加巴黎独立沙龙。1963年，和常玉是四川同乡的教育部长黄季陆造访巴黎，邀常玉到国立台湾师范大学美术系任教，并计划于国立历史博物馆举行个展。常玉欣然同意，视为人生的新开始。
1965年在巴黎友人家中举办个展。根据时任中央日报驻欧特派记者的龚选舞回忆录，常玉先将40幅（或称42幅）画作送到台湾，也拿到了中华民国政府所发的中华民国护照，并打算办完画展后定居台湾。
常玉准备动身前，突然动念赴埃及一游。当时埃及已中华民国断交，与中华人民共和国建交。驻巴黎的埃及领事不肯在中华民国护照上盖上签证，缺乏政治敏感度的常玉竟赶往中华人民共和国驻法领事馆申请护照。他误以为中华民国护照和中华人民共和国护照可以互换，就把中华民国护照留在中华人民共和国领事馆“抵押”。当看完金字塔后，他当然“换”不回那本中华民国护照。因护照问题，来台之行，只得作罢。经此变化，常玉益发消沉潦倒，过着三餐不继的生活，健康加速的恶化。
1966年8月12日凌晨，他因煤气中毒意外，去世于巴黎蒙帕纳斯工作室里。而这批事先来到台湾的画作（计42件），则一直存放在某个仓库角落里。直到1968年，由教育部移拨给史博馆典藏。


== 作品 ==
台北国立历史博物馆曾分别于1978、1984、1990年共举办三次他的回顾展，2001年常玉百岁冥诞时，历史博物馆又展出常玉百岁纪念大展，2004年6月吉美国立亚洲艺术博物馆举办常玉回顾展，展出60余件作品。足见其作为海外华人艺术家在中国画坛的重要性。主要收藏机构有：台北国立历史博物馆（52幅，包含被列为中华民国重要古物的《菊》与《四裸女》）、中国美术馆等。
1997年，时任首任台湾苏富比拍卖官工作的衣淑凡帮常玉好友摄影师罗伯特·弗兰克（Robert Frank）其所收藏的17幅画作做拍卖，拍卖所得中的400万捐给台湾国立历史博物馆，供作修复常玉晚期的画作之用。另外，在美国耶鲁大学成立了常玉奖学金，至2018年止，此奖学金仍旧存在。这17件常玉早期画作中，也包含了一幅法兰克当时最为喜爱的“常玉《母子相依》1940s，油画 纤维板，72×92.5cm”。
2006年，常玉的油画作品《花中君子》在香港苏富比春季拍卖会上以2,812万港元成交。
2009年，常玉油画《猫与雀》在春季拍卖会上以4,210万港元成交。
2011年，常玉油画《五裸女》在香港罗芙奥春季拍卖会以1.28亿港元成交，打破华人画家油画拍卖纪录。
2019年，常玉油画《曲腿裸女》在香港苏富比现代艺术晚拍中以1.97亿港元成交。在常玉生前最后一个展览中，他亲自挑选《曲腿裸女》作为邀请函的封面。除了《曲腿裸女》外，常玉尺幅最大的裸女油画《五裸女》重新登上拍卖场，在香港佳士得的晚拍中以3.03亿港元（11.6亿新台币）成交，刷新常玉油画拍卖纪录。


== 巴黎画派 ==
常玉的作品反映了他对传统与现代，东方和西方艺术传统之间联系的不懈追求，常玉是巴黎画派的活跃人物。在探索常玉与巴黎画派之间的联系之前，我们必须了解巴黎画派的含义以及它的产生背景。在欧洲，第一次世界大战的痛苦记忆导致了广泛的转变在哲学和对生存的态度上：人们迫切希望享受当下的快乐，而不关心未来。在欧洲，1920年代被称为咆哮的20年代（Les Annees Folle）。摆脱了社会法规的束缚，新的奢侈的趋势，生活方式和时尚应运而生;迷你裙变得流行，装饰艺术市场蓬勃发展，对异国东方文化的兴趣增强，尤其是对东方文化的热爱在巴黎人的生活的许多方面都可以看到它;珠宝和手表上镶嵌着东方的玉器和宝石;巴黎人吸引了中国的瓷器和明式家具;所有这些都证明了东西方交流的空前频繁。巴黎蓬勃发展为国际艺术中心，各民族的艺术家纷纷涌向巴黎，沉浸在令人振奋的自由和开放的环境中。巴黎的养育环境帮助艺术家从各自的背景中发现了个人主义的声音，被称为“巴黎画派”。因此，巴黎画派不是指艺术运动或机构，而是描述了各种风格的国际想象。
1920年，常玉在法国由政府赞助的“勤工俭学”计划，常玉在巴黎的魅力下进入巴黎蒙帕纳斯艺术区度过了四十年之久，在1920年代后期，法国学者和收藏家亨利·皮埃尔·罗氏（Henri-Pierre Roche）开始对常玉的绘画产生了浓厚的兴趣，购买了许多艺术家的作品作为他的个人收藏。当时，罗氏是巴黎新兴艺术界的重要人物。1906年，罗氏将25岁的毕加索介绍给犹太人，居住在巴黎的美国斯坦一家人，斯坦一家人随后收集了艺术家的蓝色时期和立体主义时期的重要作品，并在此重要时期成为毕加索的重要赞助人，并因此获得了成功；而罗氏则收藏了主要野兽派的许多作品。他和立体派画家经常说他对常玉的杰出创意天赋表示钦佩。在他的家中，常玉的画与马蒂斯的作品并排悬挂着。


== 纪念 ==
位于台湾历史博物馆四楼的餐厅，命名为常玉咖啡馆。


== 争议 ==


=== “常玉侄儿”跨海来台索讨百亿画作 ===
1963年，时任教育部长黄季陆曾发函邀请常玉来台湾参展与教书，常玉同意后，就自巴黎先行寄发42幅画作来台，但画家本人却因护照问题无法成行来台，致此画作则永留台湾。
1966年8月12日，常玉意外逝世，其存留于台湾之画作却一直处于无人认领状态。尔后教育部将此批画作转移交国立历史博物馆收藏管理，因近年（1997年至2016年）常玉作品逐渐受广大收藏家关注与炒作，其画作价值亦随之水涨船高（教育部内部参考常玉作品自2011年5月至2016年11月全球国际拍卖会的7笔成交行情价，换算常玉作品的平均市场价为每幅约新台币3.03亿元）。
2017年8月，常玉位居四川之亲侄子常锦茂，跨海来台委请律师，正式向台北地院提出返还所有物之民事告诉及主张继承权。中华民国教育部在法庭上主张，“人在中国[大陆地区]的常锦茂等家属没有其继承权，且常玉过世前2年都未讨还画作，已“默示”抛弃所有权”。又台北地院认为，“常锦茂是中国[大陆地区]人民，依法最多只能继承新台币200万元，超过部分归属台湾地区同为继承人，此批画作每幅平均市场价格已高达3亿零300万元”。因此法院驳回常锦茂之请求，但仍可上诉处置。
