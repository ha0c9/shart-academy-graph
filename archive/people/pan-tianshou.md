# 潘天寿（1897—1971）

- 别名 / 备注：原名天谨，字大颐，号寿者、雷婆头峰寿者
- 籍贯：浙江宁海
- 与上海美专的关系：1923 年后入上海美专，初任抄写讲义，后被刘海粟聘为中国画、中国画史教师，在此撰成《中国绘画史》（1926）。
- 艺术领域：国画、书法篆刻、美术教育、美术史论
- 核实状态：已核实

## 生平简介

潘天寿是 20 世纪中国画大家与美术教育家，精于写意花鸟和山水，兼工书法、诗词、篆刻，并擅指画，画风雄强奇崛。早年就读浙江第一师范，受李叔同、经亨颐教益，后求教吴昌硕。

他在上海美专任教期间写成中国第一部系统的《中国绘画史》（商务印书馆，1926）。1928 年起任杭州国立艺专国画系主任，抗战期间曾任国立艺专校长；1949 年后任浙江美术学院院长、中国美协副主席，建立中国画人物、山水、花鸟分科教学。文革中遭迫害，1971 年逝世。

## 年表

- 1923　任教上海美专，讲授中国画与画史
- 1926　出版《中国绘画史》；参与创办新华艺专
- 1928　任杭州国立艺专国画系主任
- 1944　任国立艺专校长
- 1959　任浙江美术学院院长
- 1981　杭州潘天寿纪念馆对外开放

## 主要贡献

- 写成中国第一部系统的《中国绘画史》
- 确立中国画人物、山水、花鸟分科教学体系
- 发起“白社”画会（1932），倡导扬州画派的革新精神

潘天寿（1897年3月14日—1971年9月5日），乳名权，原名天谨，学名天授，字大颐，早年号寿者、阿寿，晚号雷婆头峰寿者、颐者，浙江省宁海县人，中国现代画家、美术教育家。潘天寿精于写意花鸟和山水，偶作人物，兼工书法、诗词、篆刻等。与林风眠、方干民等是国立西湖艺术学院（即今中国美术学院）的主要教师。


== 生平 ==


=== 中华民国时期 ===

潘天寿幼喜习画，临《芥子园画谱》。1915年入浙江第一师范学校，得李叔同(弘一大师)、经亨颐诸师教益。1923年执教上海女子职业学校，求教吴昌硕，受器重。后入上海美术专科学校任抄写讲义职司，校长刘海粟识其才，聘任中国画、中国画史教席，遂潜心研究徐渭、朱耷、原济等大家名作。1926年参与创办上海新华艺术学院（后改新华艺术专科学校），任艺术教育系主任。1928年应聘任杭州国立艺术专科学校国画系主任。1929年赴日本考察美术教育。1932年与诸闻韵、吴茀之、张书旗、张振铎发起组织沪上“白社”画会。
抗日战争爆发后随校内迁，任合并后的国立艺专教务主任、代理校长。1944年国立艺专迁重庆后，任校长兼国画系主任。抗战胜利后随校迁回杭州。未几辞校长职，致力教育、创作，《指墨松鹰》、《读经僧》等作品均作于此时期。


=== 中华人民共和国时期 ===
中华人民共和国成立后，历任中央美术学院华东分院副院长、浙江美术学院院长、中国美术家协会副主席、美协浙江分会主席、全国文联委员、浙江省文联副主席、民盟浙江省委委员，当选第一、二、三届全国人民代表大会代表，受聘为苏联艺术科学院名誉院士，先后于京、沪、杭及香港等地举办画展。1964年回宁波故里，为南溪温泉作石兰画并题诗。
文化大革命时被关进牛棚，在浙江美院的“打潘战役”中被连续批斗。1969年初被押往宁海等地游斗，此后在重病中被押到工厂劳动，心力衰竭，卧床不起。1971年5月，有关方面对他宣读定案结论，指他是“反动学术权威”，与人民是敌我矛盾，愤慨的他大出血，没有得到及时治疗，几月后离世。
其被批斗时被满脸涂上墨汁，让他交代罪状，他说“我画画创新不好”。群众大叫“打倒反动学术权威潘天寿”，他说：“去掉‘反动’两字就可以！” 其去世前写下绝笔诗五绝：“莫嫌牢笼窄，心比天地宽。是非在罗织，自古有沉冤。”
卢炘著的《大笔淋漓：潘天寿传》记载，那时“潘天寿、吴茀之、方干民同关一室。方干民被踢得全身乌青，实在忍受不住，服大量安眠药自尽。幸亏发现得早，总算救活了。潘天寿和吴茀之也都全身浮肿，经常被打得鼻青脸肿。他们的房间经常更换，以后又日夜加锁。”


== 艺术成就 ==

潘天寿的中国画融诗词、书法、绘画、篆印为一体，笔墨雄浑，布局奇崛，意境高华，气势磅礴。其又擅指画，画风古拙厚重。有《潘天寿书画集》、《潘天寿美术文集》、《听天阁诗存》等行世。


== 拍卖纪录 ==
2015年5月，《鹰石山花图》于中国嘉德春拍以（加佣金）2.7945亿元人民币成交。
2018年11月，1963年的指墨巨制《无限风光》在中国嘉德2018年秋拍中以（加佣金）2.875亿元人民币成交，再创潘天寿作品交易记录。
2019年11月，潘天寿巨幅画作《初晴》在中国嘉德北京秋拍中以（加佣金）逾2.05亿元人民币成交。


== 家庭 ==
其父潘秉璋为清末秀才。潘天寿七岁时其母周氏病故。其子潘公凯承父业，以画闻名。

== 后世纪念 ==

1977年，杭州建潘天寿纪念馆，宁海修复潘天寿故居。潘天寿纪念馆在西湖上城区南山路景云村1号，原为潘天寿在浙江杭州的故居。
