# 程十发（1921—2007）

- 别名 / 备注：原名程潼
- 籍贯：上海松江
- 与上海美专的关系：1938 年进入上海美术专科学校学习绘画（国画系，1941 年毕业）。
- 艺术领域：国画、漫画连环画、书法篆刻
- 核实状态：已核实

## 生平简介

程十发是海派绘画代表人物，人物、花鸟独树一帜，并在连环画、年画、插图方面造诣深厚。1949 年后任华东人民美术出版社创作员，创作大量连环画，《儒林外史》插图获 1959 年莱比锡国际书籍装帧展银奖。

1957 年参与筹建上海中国画院，1984 年任院长。2019 年上海中国画院在长宁区建成程十发美术馆。

## 主要贡献

- 海派中国画代表画家
- 新中国连环画、插图艺术的开拓者
- 主持上海中国画院

程十发（1921年4月10日—2007年7月17日），原名程潼，字十发，男，上海松江人，中国画家。现存程十发美术馆。
在人物、花鸟方面独树一帜。在连环画、年画、插画、插图等方面均有造诣。工书法，得力于秦汉木简及怀素狂草，善将草、篆、隶结为一体。


== 生平 ==
1921年4月10日（农历三月初三）生于上海松江县城外岳庙镇莫家巷，1938年进入上海美术专科学校学习绘画。中华人民共和国成立后，程进入华东人民美术出版社任美术创作员，创作了大量的连环画作品。1957年，参与筹建上海中国画院，转向专门国画创作，1984年出任上海中国画院院长。2005年8月9日因小疝气手术住进华东医院。
2007年7月17日晚上6点58分因多个器官衰竭病逝于上海华东医院，终年86岁。葬于上海金山区枫泾镇枫泾公墓。


== 家世 ==
父亲程欣木，取嘉善女子丁织勤为妻，生育一子，取名程潼。小名“美孙”，取祖父程子美之孙意。程氏祖籍金山区枫泾镇，祖上世代行医，积善，在地方上历受称道。
古代有一种度量衡单位叫“髮”和“程”，《说文解字》释曰：“程，晶也。十髮为程，十程为分，十分为寸。”“程十髮”这名字就是依此据姓取名，体现文字上的机趣。
程十发已婚，妻子张金锜，长子程助，次子程多多。


== 作品与获奖 ==
有：《列宁在一九一八》、《列宁的故事》、《胆剑篇》、《画皮》、《老孙归社》、《孔乙己》等。《儒林外史》插图获1959年莱比锡国际书籍装帧展览银质奖。《孔乙己》荣获首届全国连环画绘画评奖二等奖。
