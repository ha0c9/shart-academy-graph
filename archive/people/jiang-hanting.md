# 江寒汀（1904—1963）

- 别名 / 备注：原名荻
- 籍贯：江苏常熟
- 与上海美专的关系：中年寓居上海，任教上海美术专科学校。
- 艺术领域：国画
- 核实状态：已核实

## 生平简介

江寒汀擅长花鸟，尤善禽鸟，有“江虚谷”之称，与唐云、张大壮、陆抑非并称海上花鸟画“四大名旦”。1960 年为上海中国画院首批画师，应邀为人民大会堂绘制巨幅《红梅图》。

## 主要贡献

江寒汀（1904年—1963年），原名荻，号寒汀居士，又名庚元、石溪、上渔、寒艇，中国画家。江苏常熟虞山镇人。曾任教于上海美术专科学校。


== 生平 ==
16岁从同乡陶松溪学习花鸟画，28岁开始卖画为生。中年寓居上海，任教上海美术专科学校。
1960年，为上海中国画院首批画师。因纵观宋、元名迹，悟其谨严，放纵之情，对双钩填彩，没骨写生，均所擅长，尤其描绘各种禽鸟。家中亦养许多鸟兽，供写生之用。
1963年2月6日在上海逝世，终年60岁。


== 作品风格 ==
风格近清代华岩一路，笔墨老到，色彩明丽，形象生动，构图稳健，对虚谷、任颐的画风深有研究，偶尔仿制，几可乱真，有"江虚谷 "之称。


== 著作 ==
传世作品有《杜鹊鹦鹉》、《白鹰》，有20余丈长卷《百鸟图》。

1960年应周恩来总理邀请为人民大会堂绘制巨幅《红梅图》等。
1983年上海人民美术出版社出版《江寒汀百鸟图》。
1992年古吴轩出版社出版《当代名画家江寒汀》、北京荣宝斋出版《花鸟画名家江寒洒画册》，
1995年上海人民美术出版社出版《江寒汀百卉册》。
