# 张小楼（1877—1950）

- 别名 / 备注：名柟，字小𫷹（小楼、筱楼）
- 籍贯：江苏江阴
- 与上海美专的关系：曾任教于上海美术专科学校。
- 艺术领域：国画、书法篆刻
- 核实状态：部分核实

## 生平简介

张小楼是近代文人、书画家。清末与李叔同、袁希濂、许幻园、蔡小香结为“天涯五友”，1900 年发起成立“海上书画公会”并任会长。后留学日本法政大学，民国时任北洋政府外交部编译员、驻朝鲜新义州领事等，1926 年回上海任上海铁路税务局局长，并曾任教于上海美专。其女张曼筠为李公朴夫人。

## 主要贡献

- 海上书画公会会长
- “天涯五友”之一

张小𫷹（1877年8月26日—1950年12月），名柟（或作楠），字小𫷹（或作小楼、筱楼），又号尘定居士、蓉江小楼主人，以字行。 江苏江阴人，中国近代文人、书画家。


== 生平 ==
张小𫷹出生于江阴。在清末的上海滩，他与李叔同、袁希濂、许幻园、蔡小香交往密切。 1899年，五人在许幻园的住所城南草堂结义金兰，号称“天涯五友”，并共同组成城南文社。 1900年，天涯五友在福州路杨柳楼台发起成立“海上书画公会”，张小𫷹任会长。他后来赴日本法政大学留学，回国后任南京江南高等学堂、两江优级师范学堂教习。 中华民国成立后，历任北洋政府国务院翻译官、外交部编译员、驻朝鲜新义州领事等。 1926年回到上海，曾任上海铁路税务局局长。此外，他还曾任教于上海美术专科学校。 抗日战争爆发后，他赶赴河南，协助国民政府赈济委员会副委员长屈映光赈抚黄河水灾。同时，他安排妻子等赴重庆避难。但不幸的是其妻1940年在重庆大轰炸期间惊悸而亡。此后，他的女儿张曼筠、女婿李公朴因不放心他独自在外，将他接到重庆。后又与他们夫妇一同前往昆明。 1946年，女婿李公朴遇刺身亡。此后他回到上海，生活愈发艰难。 中华人民共和国成立后，他于1950年12月在上海逝世，终年73岁。 


== 家庭 ==
张小𫷹之女张曼筠是中国近代著名社会活动家李公朴的夫人。另一女则嫁无锡石塘湾孙氏后裔孙熙文，其女孙方中是香港教育家。
